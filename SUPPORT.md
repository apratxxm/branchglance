# Support

Before asking, check the [walkthrough](docs/GUIDE.md) and the troubleshooting section of the [install guide](docs/INSTALL.md).

- **Questions and how-to:** ask in [GitHub Discussions](https://github.com/apratxxm/branchglance/discussions).
- **Bugs:** open an [issue](https://github.com/apratxxm/branchglance/issues/new/choose) and use the bug report form. Include your Windows or macOS version, the Branchglance version and steps to reproduce.
- **Feature ideas:** use the feature request form. To suggest support for another agent tool, use the new provider form.
- **Security problems:** don't open a public issue. Report them privately as described in [SECURITY.md](SECURITY.md).

Don't paste tokens, chat transcripts or other private information into any of these. Describe the behaviour instead.
