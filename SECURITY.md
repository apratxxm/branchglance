# Security policy

Branchglance reads local Codex and Claude Code files and never uploads anything, but it does install Claude Code hooks when you turn tracking on, so security reports are taken seriously.

## Reporting a problem

Please report security problems privately through [GitHub's private vulnerability reporting](https://github.com/apratxxm/branchglance/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it and what it affects. You can expect a first reply within a few days.

## Supported versions

Branchglance is in alpha. Only the latest release receives fixes.
