A small always-on-top widget for Codex and Claude Code. Every chat and subagent in one tree, the ones stuck on a question, and how much of your 5-hour and weekly limits is left.

Download for Windows Build on macOS

Three chats are running. One finished ten minutes ago. One has been waiting on a yes or no since lunch. Your weekly limit is at 81% and you have no idea which chat did it.

Branchglance sits in the corner of your screen and keeps that straight, so you don't have to tab through every terminal to find out.

Local and opt-in

It reads status, not your work.

Everything runs on your machine. Claude collection is off until you turn it on in Settings, and turning it off removes only the hooks Branchglance added.

Reads

  • Which chats and subagents exist, and how they nest
  • Running, waiting and finished states
  • Token counts, cache rates and model names
  • 5-hour and weekly limit readings

Never collects

  • Your prompts
  • Tool inputs or outputs
  • Full file paths
  • Chat titles from hook events

Install

Two minutes on Windows. One script on macOS.

  1. Download BranchglanceSetup.exe from the releases page. Alpha builds are pre-releases.
  2. Run it from File Explorer as your normal user, not as administrator.
  3. Open Branchglance from the Start menu.
PowerShell · verify the download
Get-FileHash .\BranchglanceSetup.exe -Algorithm SHA256

Needs 64-bit Windows 10 (19041) or 11, WebView2 and .NET Framework 4.8, which ship with current Windows. Alpha builds aren't code-signed yet, so SmartScreen may warn on first run.

  1. Install Python 3 and the Xcode command line tools.
  2. Build from a checkout. The script installs the notch app in /Applications.
Terminal
git clone https://github.com/apratxxm/branchglance.git
cd branchglance
./macos/build.sh install

Builds without a Developer ID are signed locally for the machine that built them. See the macOS guide for rollback and uninstall.
