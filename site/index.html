Four jobs the widget does for you

One tree, read from your local sessions.

Chats waiting for input are marked in the tree and counted in the toolbar. Click the count, then open the exact chat.

Each provider gets a 5-hour band and a weekly band, amber at 50% and red at 70%. A countdown at zero counts as a reset only after a fresh reading.

Start Codex jobs with bg-codex from a Claude Code chat and they nest under that chat. Subagents past the first three fold behind +N more.

On Windows the widget collapses to a 328 px strip with a clock and limit bands. Hover, or press Ctrl+Shift+T, to open the tree.

Branchglance reads local files only: Codex session data, Claude Code transcripts and hook events, and Claude Desktop's usage cache. There is no account, server or telemetry, and nothing is uploaded.

Claude collection is off by default. You turn it on in Settings, under Notifications.

Hook events carry metadata. They hold no prompts, tool inputs or outputs, full paths or chat titles.

Turning tracking off or uninstalling removes only the hooks Branchglance added.

Questions before you install

Something missing? Open an issue on GitHub

Do I need Claude Desktop?

No. Codex must be signed in for Codex chats and limits. Claude Code is optional, and Claude Desktop only supplies Claude limits.

Does it change my Claude Code settings.json?

Only with Claude tracking on. It backs up settings.json and adds its own hooks.

How do I install it on macOS?

Install Python 3 and the Xcode command line tools, then run ./macos/build.sh install from a checkout. It puts the app in /Applications.

Why does Windows SmartScreen warn me?

Alpha builds are not code-signed yet. Compare the download's SHA-256 hash with the .sha256 file published next to it.

How do I uninstall it?

Settings, Apps, Installed apps, Branchglance. Your settings and history in %LOCALAPPDATA%\Branchglance are kept.
