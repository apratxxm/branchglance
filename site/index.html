Local and opt-in

It reads status,
not your work.

Branchglance runs on your machine. Claude collection is off until you turn it on, and turning it off removes only the hooks Branchglance added. Hook events carry metadata, not prompts, tool inputs or outputs, full paths or chat titles.

Questions, answered

No. It reads local files only: Codex session data, Claude Code transcripts and hook events, and Claude Desktop's usage cache. There is no account, server or telemetry. The one opt-in exception is reset greetings, which run the provider's own CLI.
